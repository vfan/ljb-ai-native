配套项目

两个可以跑起来的配套项目

一个用来练评测，一个是 Go 课程的源码主线。

MEETING-EVAL · GO 1.22+

会议行动项评测台

固定评测“从会议记录提取行动项”：两版提示词、14 条边界样本、规则评分 + AI 裁判、版本对比和发布门禁。它把“评什么、怎么评、评完怎么改”做成一个能点开的平台。

本地运行 
cd examples/meeting-eval
cp .env.example .env
# 填写 DEEPSEEK_API_KEY
go run .
# http://127.0.0.1:8765

复制 .env.example 为 .env，填写 DEEPSEEK_API_KEY（必填）后再启动。

EINO-OA · GO + REACT

学业助手源码主线

服务端 Agent 课程逐步拆解的真实项目：Gin + GORM + SQLite 后端、React + Vite 前端、Eino ReAct Agent 与业务工具。课程中的 backend/… 路径都相对于这个目录。

本地运行 
# 终端一：后端 :8080
cd examples/eino-oa/backend
cp .env.example .env
# 填管理员账号与 DEEPSEEK_API_KEY
go run ./cmd/server

# 终端二：前端 :3000
cd examples/eino-oa/frontend
npm install
npm run dev

要求 Go 1.25+、Node.js 20.19+。在 backend/.env 设置管理员账号 ADMIN_USERNAME / ADMIN_PASSWORD（密码必填），并填写 DEEPSEEK_API_KEY（必填）；启动后访问 http://localhost:3000，用该账号登录。
